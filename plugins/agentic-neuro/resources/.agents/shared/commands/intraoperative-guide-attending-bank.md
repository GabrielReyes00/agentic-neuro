# Intraoperative Guide Attending Bank

The reusable question bank is reference data, not executable policy:

`data/reference/operative-attending-question-bank.md`

Load it only when the procedure's Coverage Matrix or an optional rehearsal needs
attending-style probes. Select questions by applicability and record their bank
IDs in `bank_questions_pulled`; do not impose a minimum count. Adapt wording to
the case without changing the tested decision. Questions created for a genuinely
uncovered procedure-specific issue go in `fresh_questions`, not the bank list.

The map and expert review contracts own grading and readiness decisions. A bank
question is an assessment prompt, not evidence that the guide covered the topic
or that the learner mastered it.
